# Reloaded-II

### Universal, high-performance game mod loader

Reloaded-II is a free, open-source, universal game mod framework focused on performance and flexibility. Its dependency-aware system and hot-swappable mods make it the most advanced modding platform for supported games.

<br>

---

## Features

| | |
|:---|:---|
| **Universal Framework** | Works with any Windows game — not limited to specific titles |
| **Mod Dependencies** | Automatic dependency resolution so mods install in the right order |
| **Hot Reload** | Load and unload mods at runtime without restarting the game |
| **Persona & Sonic** | Deep support for the Persona and Sonic modding communities |
